# @j-groupware/ui

Shared React components and design tokens for the j-groupware customer UI. Import `@j-groupware/ui/styles.css` once at the application entry point and import components from `@j-groupware/ui`.

See [`docs/ui-guidelines.md`](../../docs/ui-guidelines.md) for layout, accessibility, and responsive expectations. Components use React 19.3.0 as a peer dependency.
